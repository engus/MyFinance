Хочу создать веб-приложение, для ведения простой домашней бухгатерии. 

Первая часть. 
- Приложение отслеживает приходы денег - income, для обычной семьи / человека их чаще всего немного и они приходят редко (1-2 раза в месяц) и пользователь вводит остатки по своим счетам (карты, бакновские счета, если нужно наличка)
приложение уже само определяет реальные траты за месяц

То есть, пользователь вводит начальные позиции, и в конце месяца обновляет показатели по картам и счетам, его ЗП, приходы он вводит при начале работы с приложением (но при этом , эти данные можно изменять, добавлять, удалять, отключать) , программа по итогу расчитывает его траты. при этом пользователь может вводить и крупные траты (авто, кредиты, ипотеки и тд), программу уже сможет сама аттрибуцировать траты / приход. не размеченные траты будут отмечены как другое.

- При этом должна использоваться - двойная бухгателская запись. То есть недолжно быть неучтенных денег\ приходов


Вторая часть.
- Отслеживать пользовательские активы: дома, квартиры, авто, ценные бумаги, наличность и тд
тем самым пользователь будет понимать во сколько оцениваются все его активы. 

Функционал: 
- логин / создание  / удаление / редактировние аккаунта
- страница с дашбордом - показываются траты / приходы / активы. вся основная информация 
- страница с cashflow - пользователь может редактировать / создавать / удалять приходы/уходы. там же может обновлять данные по остаткам за период. 
- страница с активами, где пользователь создает / редактирует свои активы
- страница с настройками + аккаунт
- пользователь может выбирать разную валюту для любого из приходов/трат/активов. но при этом на странице с дашбордом должен видеть все в единой валюте (которую может сменить, например доллары по умолчанию)
- протестируй основную логику.
- по готовности оформи PR и код-ревью
- приходы \ траты должны разделяться на one-off и переодичные. переиодичность можно настраивать (неделя, месяц, квартал, год, кастомная)
- приложение должно быть БЕЗОПАСНЫМ. 

Для кого: 
- пользователь который не хочет тратить много времени на бухгалтерию но хочет понимать где он и что у него есть по финансам/активам 
- он может работать в нескольких странах, также и активы у него распределены на несколько стран/ регионов
- думаю что у моего пользователя есть деньги от 10 тыс долл до 20 миллионов. 

Хочу видеть визуальные варианты дизайна в браузере - покажи мокапы при проектировании.
