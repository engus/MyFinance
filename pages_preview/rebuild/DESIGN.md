# MyFinance rebuild — selected visual system

Open `index.html` through a local static server. The mockup is interactive:

- navigate Dashboard, Cashflow, Assets, and Settings;
- open and close the Reconciliation dialog;
- resize the browser to inspect the mobile bottom-navigation layout.

## Calm Ledger

The selected direction uses bright surfaces, navy typography, indigo actions, compact analytical cards, and restrained green/red financial states. It prioritises clarity, familiarity, and information density without looking like a generic expense tracker.

The system will be implemented with:

- a light neutral canvas and white elevated surfaces;
- navy primary text and muted blue-grey supporting text;
- indigo primary actions and focus states;
- green for positive financial states, red for negative states, and amber for warnings;
- rounded cards, compact tables, and responsive desktop sidebar/mobile bottom navigation;
- explicit loading, empty, error, stale-data, and reconciliation states;
- accessible labels, visible keyboard focus, and motion that respects reduced-motion preferences.
